# 💆‍♀️ Aesthetic Clinic System

Sistema em desenvolvimento para gerenciamento de clínicas, focado em controle de atendimentos, agenda, pacientes, profissionais e financeiro.

---

## 🚀 Sobre o projeto

O **Aesthetic Clinic** é um sistema desenvolvido com foco em organizar e automatizar os processos de uma clínica, como:

- Cadastro de pacientes e profissionais
- Agendamento de procedimentos
- Registro de sessões e atendimentos clínicos
- Controle financeiro básico
- Gestão de prontuário

O projeto está em fase de desenvolvimento e evolução contínua.
---

## 🛠️ Tecnologias utilizadas até o momento

- Java 17+
- Spring Boot
- Spring Data JPA / Hibernate
- PostgreSQL
- Maven
